# Hinweise für dieses Repository

## Websites
- Jede Website in diesem Repository bekommt unten in der Fußzeile auf allen Seiten (Startseite, Impressum, Datenschutz usw.) einen kleinen, unaufdringlichen Ersteller-Hinweis:
  `Website erstellt von Janosch Krause`
  Gestaltung: eigene Zeile unter dem restlichen Fußzeilen-Inhalt, kleine Schrift (ca. 0,72rem), leicht abgeschwächt (opacity ca. 0,7), ohne Link.
