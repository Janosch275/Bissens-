# Astoria – Griechisches Restaurant Bad Nenndorf

Statische One-Page-Website (HTML/CSS/JS, keine Build-Tools).

- `index.html` – Startseite
- `style.css`, `main.js` – Gestaltung und „Jetzt geöffnet“-Anzeige
- `impressum.html`, `datenschutz.html` – Platzhalter, vor Livegang ausfüllen

Lokal ansehen: `index.html` im Browser öffnen oder `python3 -m http.server`.
